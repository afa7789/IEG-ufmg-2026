Sobre o projeto

Criptografia 2026/2 · DCC/ICEx/UFMG · Prof. Jeroen van de Graaf · Projeto de implementação.

Ideia

Uma caixa de entrada pública onde qualquer pessoa pode deixar uma mensagem que só o destinatário lê. O blockchain (Ethereum) serve como registro de chaves públicas e canal de entrega; a confidencialidade vem inteiramente do ElGamal, executado fora da cadeia.

On-chain vs off-chain

O contrato MessageInbox não sabe o que é ElGamal. Ele guarda bytes: uma chave pública por endereço e uma lista de pares (c1, c2) por destinatário. Geração de chaves, cifragem e decifragem acontecem no navegador. Trocar o esquema (por exemplo, para EC-ElGamal) não exige mudar o contrato.

ElGamal clássico

Grupo multiplicativo Zp*, p primo seguro, gerador g.

Chavesx aleatório em [1, p−2]; y = gx mod p. Pública: (p, g, y). Privada: x.
Cifrar mk aleatório; c1 = gk mod p; c2 = m · yk mod p.
Decifrarm = c2 · (c1x)−1 mod p.

Grupo fixo modp/ietf/2048 (RFC 3526, g = 2). A mensagem UTF-8 vira um inteiro big-endian e precisa ser menor que p: cabem 255 bytes. A chave pública vai on-chain como DER (SubjectPublicKeyInfo, ~814 bytes, carrega p, g, y); o ciphertext é c1 ‖ c2 com 256 bytes cada.

Fluxo
  1. Alice gera (p, g, y, x) e registra (p, g, y) ABI-codificados em registerPublicKey.
  2. Bob lê publicKeys(alice), cifra localmente e chama sendMessage(alice, c1, c2).
  3. Alice lê getMessages(alice) e decifra com x, que nunca saiu do navegador dela.
Stack
ContratoSolidity 0.8.20, Foundry. Deploy pela UI (viem) ou via forge create.
ElGamalBotan 3.14 (C++) compilado para WebAssembly com Emscripten. Ponte em C (wasm/bridge.c) sobre a API FFI: keygen, encrypt, decrypt com padding Raw. Nenhuma aritmética modular escrita à mão.
FrontendHTML/CSS/JS sem bundler; viem via esm.sh, ElGamal via .wasm local (768 KB). Hospedado no GitHub Pages.
RedesAnvil local (31337) e Sepolia (11155111).
Limitações (de propósito)
  • ElGamal textbook: maleável, sem padding, sem segurança CCA. Serve para estudar o esquema, não para uso real.
  • Padding Raw: o inteiro é a própria mensagem. Botan oferece OAEP, mas aqui o objetivo é ver o esquema cru.
  • Chave privada no localStorage, em claro.
  • Metadados (quem fala com quem, quando) são públicos na cadeia.
